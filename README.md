# Portfolio — Àlex Gros Aguilera

Portfolio personal bilingüe (ES / EN) con mi experiencia, formación y habilidades.

🔗 **Web:** https://alex-gros.github.io/portfolio-web/

## Características
- Cambio de idioma español / inglés sin recargar la página (diccionario en JavaScript)
- Diseño responsive con HTML y CSS puros, sin frameworks
- Secciones: sobre mí, experiencia, educación, habilidades, proyectos y contacto

## Tecnologías
HTML5 · CSS3 · JavaScript (vanilla) · Google Fonts

## Estructura
```
index.html      → página principal
css/style.css   → estilos
js/script.js    → cambio de idioma
assets/         → imágenes
```

## Ejecutar en local
Abre `index.html` en el navegador. No necesita instalación.
